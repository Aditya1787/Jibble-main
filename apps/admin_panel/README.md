# Jibble Admin Panel

React + TypeScript + Vite admin console for the Jibble platform.

## Stack
- React 18
- TypeScript 5
- Vite 5
- React Router v6
- Zustand (state management)
- TanStack Query (data fetching)
- Recharts (analytics charts)
- Axios (HTTP client)

## Getting Started

```bash
npm install
npm run dev
```
