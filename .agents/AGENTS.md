# Project Customization Rules - Jibble Community App

## Core Product Domain
- **General Community Platform**: Jibble is a general-purpose community application designed for anyone, including creators, interest groups, clubs, and organizations. It is **NOT** a college-exclusive social media platform.
- **Onboarding and Community Creation Flow**:
  - When users sign up, they search for their desired community.
  - If a community is not found, users can request/create one.
  - The creation wizard collects the community name and key features.
  - The application checks whether a similar community already exists to avoid duplicates.
  - If no match is found, the user can create and initialize the new community.
