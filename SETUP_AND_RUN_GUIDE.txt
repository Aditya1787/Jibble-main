PART 1: SUPABASE CONSOLE SETUP (FOR ADMIN BACKEND & ADMIN PANEL)
================================================================================

1. Create Supabase Project:
   a. Log in at https://supabase.com
   b. Click "New Project" -> Name: `Jibble-Admin-Backend` -> Set Database Password.
   c. Choose region (e.g., Mumbai / San Francisco).

2. Execute SQL Database Schema:
   a. In Supabase Console, open "SQL Editor" from the left menu.
   b. Click "+ New Query".
   c. Open file: `d:\for opening\for opening\Jibble\database\001_admin_panel_schema.sql`
   d. Copy the complete SQL text and paste into the SQL Editor.
   e. Click "RUN" (or press Ctrl+Enter).
   -> Creates 10 tables: employees, job_categories, job_roles, teams, team_members, projects, tasks, policies, privacy_settings, audit_logs.

3. Get Supabase API Keys:
   a. Go to Project Settings (⚙️ icon) -> API.
   b. Copy 3 credentials:
      - Project URL          (e.g., https://xyz.supabase.co)
      - `anon` `public` key  (starts with eyJ...)
      - `service_role` key   (starts with eyJ... — server secret)

4. Configure Auth Settings (Optional for Dev):
   a. Go to Authentication -> Providers -> Email.
   b. Turn OFF "Confirm email" for instant login during testing.

PART 2: FIREBASE CONSOLE SETUP (FOR FLUTTER MOBILE APP & PUSH NOTIFICATIONS)
================================================================================

1. Create Firebase Project:
   a. Log in at https://console.firebase.google.com
   b. Click "Add Project" -> Project Name: `Jibble-Mobile-App` -> Click Continue.
   c. (Optional) Enable Google Analytics -> Click "Create Project".

2. Register Android App in Firebase:
   a. Click the Android icon (🤖) in project overview.
   b. Package name: `com.jibble.app` (matches package in `apps/mobile_app`).
   c. App nickname: `Jibble Mobile Android`.
   d. Click "Register App".
   e. Download `google-services.json`.
   f. Place `google-services.json` inside:
      `d:\for opening\for opening\Jibble\apps\mobile_app\android\app\google-services.json`

3. Register iOS App in Firebase (if building for iOS):
   a. Click "Add App" -> iOS icon (🍎).
   b. Bundle ID: `com.jibble.app`
   c. Download `GoogleService-Info.plist`.
   d. Place `GoogleService-Info.plist` inside:
      `d:\for opening\for opening\Jibble\apps\mobile_app\ios\Runner\GoogleService-Info.plist`

4. Enable Firebase Cloud Messaging (FCM for Push Notifications):
   a. In Firebase Console, go to Project Settings (⚙️ icon) -> Cloud Messaging tab.
   b. Ensure "Firebase Cloud Messaging API (V1)" is Enabled.
   c. Copy the FCM Server Key or Service Account credentials for push notification triggers in mobile backend.

5. Automatic FlutterFire CLI Config (Recommended):
   a. Install FlutterFire CLI: `npm install -g firebase-tools` & `dart pub global activate flutterfire_cli`
   b. Run inside mobile app folder:
      `cd apps/mobile_app`
      `flutterfire configure`
   c. Automatically generates `lib/firebase_options.dart` with all keys.
