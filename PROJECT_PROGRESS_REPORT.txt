PART 2: DETAILED STEP-BY-STEP GUIDE FOR YOU (THE USER)
--------------------------------------------------------------------------------

STEP 1: FIREBASE & PUSH NOTIFICATIONS SETUP
  1. Go to console.firebase.google.com and create a project named "Jibble".
  2. Add Android App (package name: com.jibble.app).
     - Download google-services.json
     - Save to: apps/mobile_app/android/app/google-services.json
  3. Add iOS App (Bundle ID: com.jibble.app).
     - Download GoogleService-Info.plist
     - Save to: apps/mobile_app/ios/Runner/GoogleService-Info.plist
  4. Copy Cloud Messaging Server Key into backend/.env under FIREBASE_SERVER_KEY.

STEP 2: CLOUD MEDIA STORAGE SETUP (AWS S3 or Cloudinary)
  1. Create an AWS Account and create an S3 Bucket named "jibble-media-uploads".
  2. Configure CORS policy to allow uploads from mobile and web apps.
  3. Copy AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_REGION, AWS_S3_BUCKET_NAME.
  4. Save keys into backend/.env.

STEP 3: PRODUCTION DATABASE & REDIS HOSTING
  1. PostgreSQL: Create a database on Supabase (supabase.com) or Neon (neon.tech).
     - Save connection string into backend/.env under DATABASE_URL.
  2. Redis: Create a Redis instance on Upstash (upstash.com).
     - Save Redis URL into backend/.env under REDIS_URL.

STEP 4: DEVELOPER ACCOUNTS (FOR APP STORES)
  1. Google Play Console Account ($25 one-time fee at play.google.com/console).
  2. Apple Developer Program Account ($99/year fee at developer.apple.com).

STEP 5: APP STORE GRAPHICS & ASSETS
  - App Logo: 1024x1024 px PNG.
  - Feature Graphic (Android): 1024x500 px.
  - Screenshots: iPhone (6.5-inch & 5.5-inch) and Android Phone screenshots.
  - Privacy Policy URL link.

STEP 6: PHYSICAL DEVICE TESTING
  - Test camera capture, push notification banners, and smooth video playback on real phones.
